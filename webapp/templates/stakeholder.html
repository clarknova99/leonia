Leonia traffic — map explorer

Simulation animates a precomputed SUMO model of a street change across a 24-hour day. All maps render on the GPU with deck.gl over a token-free MapLibre basemap.

About this view

Traffic averages come from StreetLight measured volumes (Zone Activity hourly shape × StreetScanner daily levels), keyed to the SUMO street network. Weekday peaks reflect the AM/PM commute; Sunday peaks reflect a midday plateau, so the Peak AM / Peak PM windows differ by day type.

Crash points are NJDOT records (2019–2026), borough-filtered to local streets.

About this view

Each dropdown combination maps to a precomputed SUMO simulation. The map animates that scenario's per-link vehicles/hour in 15-minute frames across a 24-hour day, drawn on the GPU with deck.gl over a token-free MapLibre basemap.

Closures and speed humps apply at runtime via libsumo; one-way conversions are baked into a fresh SUMO network via netconvert before each scenario run, since lane topology can't be changed mid-simulation.
